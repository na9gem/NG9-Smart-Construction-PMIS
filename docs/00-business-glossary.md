# Business Glossary

## Purpose

Business Glossary คือพจนานุกรมคำศัพท์มาตรฐานของระบบ NG9

เอกสารนี้ใช้เป็นมาตรฐานเดียวกันสำหรับ

- Business
- Database
- Backend API
- Frontend
- Dashboard
- AI
- Documentation

ทุกคนในทีมต้องใช้คำศัพท์เดียวกัน

---

# 1. Organization

## Definition

องค์กรที่เป็นเจ้าของข้อมูลภายในระบบ

## Examples

- NG9 Engineering
- Department of Highways
- Royal Irrigation Department

## Database

organizations

---

# 2. Project

## Definition

โครงการก่อสร้างหนึ่งโครงการ

## Examples

- โรงพยาบาล
- อาคารสำนักงาน
- ถนน
- สะพาน

## Database

projects

---

# 3. Contract

## Definition

สัญญาที่เกี่ยวข้องกับโครงการ

หนึ่งโครงการสามารถมีได้หลายสัญญา

## Database

contracts

---

# 4. Construction Object

## Definition

องค์ประกอบที่ก่อสร้างจริงในหน้างาน

## Examples

- Pile
- Footing
- Column
- Beam
- Slab
- Wall
- Road
- Bridge Pier

## Database

construction_objects
